# DDF Funders Network

An interactive network of the funders that have pooled money with the Doris Duke Foundation, built with D3.js for a data visualization class.

- **Live page:** served by GitHub Pages from this repo's root (`index.html`)
- **How it was built:** [how-claude-built-this.html](how-claude-built-this.html)
- **Data:** `data.js` (13 programs, 80 funders, with a source link for each program)

Built with Claude (Anthropic). The reference design is https://ddf-constellation.vercel.app.
